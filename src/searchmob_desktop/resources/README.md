# App resources

Placeholder icon set for the Briefcase build. The current `icon.png` (and the
`icon-{16,32,64,128,256,512}.png` per-density variants) is a flat yellow square
with a centred magnifying-glass glyph, generated programmatically.

The final icon will be ported from the Android repo at
`~/Projects/SearchMob/app/src/main/res/drawable-*/ic_launcher_foreground.png` in
a follow-up commit; the file names will stay the same so the Briefcase config
keeps working unchanged.
